# Amazon Lite Demo

Simple Amazon-inspired e-commerce demo with login, cart, checkout, and saved orders using a SQLite database.

## Features
- Login and register
- Cart stored in the browser
- Checkout creates an order in SQLite
- Orders page retrieves orders for the logged-in user

## Run
```powershell
cd "d:\Placement\Amazon"
npm install
npm start
```
Open http://localhost:3000

## Notes
- Passwords are stored in plaintext in the database (not secure).
- This is a demo setup for learning purposes.
